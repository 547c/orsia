# 픽셀 효과 · 음계 고리 연결 명세 (초안)

본편 `p2_battle_view.gd`의 2D 전투에 붙였다(막기 결과 `_parry_px` · 내 공격 접촉 `_hit_px` · 적 차례 고리 `_ring_show`, 효과는 정수 3배). 3D 무대 실험실에는 아직 붙이지 않았다.

## 1. 효과가 받는 최소 값

새 전역 이벤트 버스 없이, 부르는 자리에서 바로 만든다.

```gdscript
var fx := P2PxFx3D.new()            # 2D 화면은 P2PxFx2D
fx.position = 바닥_기준점           # 3D: 무대 좌표(배우 원본 1px = 1) / 2D: 화면 좌표(노드 scale = 배우 배율)
world_fx_parent.add_child(fx)
fx.play(P2PxSheet.get_sheet(종류), 접촉_음악시각, _music.clock, 왼쪽을_향함)
```

| 값 | 형태 | 지금 코드에서 나오는 곳 |
|---|---|---|
| 종류 | 시트 이름 `slash_basic` · `hit_spark` · `parry_perfect` | 카드 · 판정 결과 |
| 대상 / 공격 방향 | `flip`(원본은 오른쪽을 향함). 적이 주인공을 치면 `true` | 공격자 index · 대상 index |
| 바닥 기준점 | 베기 = 공격자 발 · 맞는 순간 = 맞는 쪽 발 · 패링 = 막는 쪽 앞 바닥(발에서 공격 쪽으로 약 22) | 3D: 배우 발(`(-86,0,-5)` 등) / 2D: `FEET_Y` 줄의 배우 x |
| 접촉 음악시각 | `P2Music.clock` 기준 초. 효과는 이 시각에서 접촉 장까지의 시간만큼 앞서 시작 | 아래 2 |
| 판정 등급 | `perfect` → `parry_perfect` · `good` → (막음용 효과는 다음 셋에서, 후보 `shield-block`) · `miss` → 주인공에게 `hit_spark` | `P2NoteChart.judged` |

## 2. 접촉 타이밍

- 효과는 입력 결과와 기존 피해 시점에 맞춘다. 공격을 가장 가까운 8분박으로 끌어오려고 기다림을 넣지 않는다.
- 막기:
  - `_on_note_judged`에서 등급을 받는 순간이 곧 노트 박이다. 접촉 음악시각은 `chart.t0 + note.at`(이미 막기 음이 쓰는 값)이다.
  - 적 쪽 `_strike_contact`(노트가 닫히는 순간)도 같은 박이다.
- 내 공격: 공격 동작의 접촉 장 시각을 미리 알면(`_art_attack_in`의 접촉 프레임) 그 시각을 넘겨 휘두름 장부터 보인다. 모르면 지금(`_music.clock()`)을 넘기고 접촉 장부터 보인다(베기 휘두름 2장 ≈ 0.07초 생략).
- 박에 맞추는 실험은 본체가 아니라 여운 쪽부터 한다(빛이 다음 8분박에 잦아들기, 보조 반짝임).

## 3. 빛 두 가지와 층

- 현재 실험실 세계 층: 건축 1 · 3D UI 2 · 물 4 · 배우 8. 효과 판은 배우 층(8)이다.
- **빛 마스크**(`*_light.png`)는 효과 판 위에 더하기로 얹는 그림일 뿐 장면을 비추지 않는다. 늘 켠다(효과 줄이기면 끔).
- **실제 3D 순간 광원**은 `light_flash = true`일 때만 쓴다.
  - OmniLight3D가 시트의 장별 빛 양(`meta.glow`)과 평균 색(`meta.glow_color`)으로 켜졌다 꺼진다.
  - `light_cull_mask` 기본 1 | 8(건축 · 배우)이라 3D UI(2)와 물(4)은 비추지 않는다. 물까지 비출지는 화면 보고 정한다.
  - 안개 기여는 0(`light_volumetric_fog_energy = 0`)이다.
  - 노트 · 판정 원은 2D 화면 층이라 3D 광원과 무관하다.

## 4. 시간 · 줄이기 · 소리

- 장은 늘 바깥 음악 시각(`clock`)으로 고른다. 멈추면 멈추고, 되감으면 그 장으로 간다. 새 시계 · 매니저 · 전역 time_scale은 없다.
- 효과 줄이기(`reduced`): 빛 마스크와 순간 광원을 끄고 본체만 보인다.
- 효과는 소리가 없다. 막는 동안 꺼 둔 음악 밖 효과음(방패 철컥 · 북 쿵 · 딱)은 다시 켜지 않는다. 새 유료 효과음 · 음악도 없다.

## 5. 크기

- 시트는 1배 논리 픽셀이다(배우 원본 1px = 효과 1px). 3D에서는 `pixel_size 1`이라 배우와 같은 원근 배율로 보인다(선택 화면 약 3.5배, 막기 구도 약 2.5배).
- 2D에서는 노드 scale을 배우와 같은 값으로 둔다.

## 6. 음계 고리 (`P2ScaleRing`)

- 데이터: `p2/scale_ring/worlds.json`. `tools/music/extract_worlds.mjs`로 음악 엔진에서 뽑으며, 음원은 다시 굽지 않는다. 공통음(지금 데이터로 도 · 솔)도 데이터로 센다.
- 매 프레임: `feed(_music.clock(), _music.beat, _music.bar, _music.earned)`
- 판정: `note_hit(막기 음 semi, grade, 접촉 음악시각)`. 길게 누르기는 `hold(semi, true/false, 시각)`이며, 본편 `_on_note_struck`의 k == 0과 판정 끝에 맞출 자리다.
- 세계: 차례 세계가 정해질 때 `set_world(세계, 들어가는 문장 at − 한 박, 한 박)`. 필인 한 박 동안 다각형이 바뀐다.
- 붙일 자리 후보: 막기 동안 에너지 구슬 자리. 아직 붙이지 않았다.
