# 혼합 리듬 무대 실험 (Godot)

명세: CLAUDE_CLOUD_STAGE_01 / 01_PROMPT_KO.txt. 본편 시작 장면 · 자동 로드 · 세이브 · 전투 흐름은 바꾸지 않았다.

## 실행

에디터에서 프로젝트를 열고(참조 PNG 가져오기) `res://tools/stage_lab/godot/stage_lab.tscn`을 연 뒤 현재 장면 실행(F6).

## 조작

| 키 | 하는 일 |
|---|---|
| 1 / 2 | A(간단한 2D 바닥 받침) / B(3D 바닥 · 낮은 단차 · 빛 하나). 고르기 구도일 때만 |
| Space | 막기 시작: 다음 문장 첫머리에 악보, 그 전 첫 cue 앞에 고르기 → 막기 구도 전환 |
| H | 구간: N1 탭 ↔ 홀드(같은 마디에 본편 고리 '길게' 규칙) |
| [ / ] | 도트 배율(정수 n, 화면 n px = 원화 1도트). 기본은 화면 높이에 맞춘 값 |
| L | 바닥 빛(악보 반주 cue의 박에 맞춰) 켜고 끄기 |
| R | 고정한 고리 마디를 풀기(다음 막기에서 다시 정함) |
| F7 | 자동 막기(본편 P2Music 그대로) |
| Esc | 악보 멈춤 |

판정: 클릭 또는 누르기 키(본편 리듬 설정 그대로).

## A/B에서 같은 것

- 음악: 본편 P2Music(계면 · 일반 112BPM, 척후 둘 = N1), 진입 대기 · 필인 · 막기 음 정책 그대로
- 노트: 본편 P2NoteChart. 첫 막기에서 정한 고리 마디를 고정해 A/B가 같은 마디 · 같은 노트 배열
- 화면 자리 · 반경(P2BattleView.NOTE_R) · 판정 창(세계 음악 전투 기본 1.5배) · 보정(리듬 설정 offset)
- 인물 · 바닥 끝 · 바닥 빛의 화면 자리(stage_space.gd 한곳에서 계산)

## 파일

- `stage_lab.tscn` / `stage_lab.gd`: 장면 · 음악 · 악보 · 구도 전환 · 조작
- `stage_space.gd`: 무대 ↔ 화면 좌표, 정수 도트 배율, 고르기/막기 구도 값
- `stage_view_3d.gd`: B(저해상도 SubViewport 3D, 카메라를 향한 판으로 세운 인물)
- `stage_view_2d.gd`: A(같은 자리 · 같은 타일의 납작한 바닥)
- `ref/`: 첨부 참조 PNG 복사본(수호자 · 강아지 64×64). 사용자 Aseprite 마스터가 아님
